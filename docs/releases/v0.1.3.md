# v0.1.3 — Windows hooks actually launch

This patch closes a Windows release blocker found during fresh-host acceptance: Codex 0.147.0 could not execute the quoted `commandWindows` emitted by earlier releases when Node.js or the hook lived under a path containing spaces.

## Changes

- Install a minimal Windows batch wrapper containing the normally quoted Node.js and hook paths.
- Register only the wrapper's validated, quote-free NTFS short path in `commandWindows`.
- Fail installation closed when Windows cannot provide a safe single-token wrapper path.
- Exercise the exact registered command through `cmd.exe` in the Windows regression suite.
- Extend setup and host-acceptance checks to bind the wrapper, `hooks.json`, and exact platform command.

The workaround addresses the command parsing behavior tracked in [openai/codex#38168](https://github.com/openai/codex/issues/38168). Non-Windows installations retain the existing direct Node.js command.

## Verification

- `npm run verify`: 11 tests pass.

- One fresh Codex 0.147.0 manual-compaction regression with `gpt-5.6-sol` received exactly one immediate registered `AGENTS.md` reload and no replay on the next ordinary turn.
