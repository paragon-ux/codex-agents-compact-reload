# v0.1.0 - Project rules, reloaded

Compaction is useful. Forgetting which project rules govern the next step is not.

This first public release adds a small, dependency-free Codex lifecycle hook that reloads the registered Git root's `AGENTS.md` into the immediate compact continuation. It makes the recovery source visible, hashes the exact instruction bytes, and fails closed when a registered instruction file is unsafe or invalid.

## Highlights

- Project-scoped `SessionStart` handling for compact continuations.
- Strict UTF-8 decoding, a 32 KiB bound, canonical Git-root checks, and containment validation.
- SHA-256 binding for the exact reloaded `AGENTS.md` bytes.
- Idempotent installation that preserves unrelated hooks.
- Explicit no-op behavior outside registered projects.
- An original compact-continuity icon and a public rationale comparing no hook, manual recovery, and Ralph-style loops.
- Cross-platform CI across Node.js 20, 22, and 24 on Windows and Linux.

## Compatibility snapshot

This release was locally verified with:

- `codex-cli 0.147.0`;
- Node.js 22; and
- Git for Windows.

The Codex version is an evidence-bound compatibility snapshot, not a declared minimum. Hook availability and event behavior depend on the installed Codex build.

The automated suite simulates the documented hook payload and exercises a temporary Codex-home installation. A real automatic or manual Codex compaction remains a host-level acceptance check.

## Boundaries

The hook restores instructions; it does not prove that an agent followed them. It does not inspect transcripts, prompts, tool results, credentials, or private task artifacts, and it does not authenticate the live repository or phase state.
