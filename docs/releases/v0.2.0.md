# v0.2.0 — Universal AGENTS.md Compact Reload & Multi-Harness Support

This minor release broadens the project from an OpenAI Codex-exclusive hook into a universal, multi-harness post-compaction bootloader for `AGENTS.md`.

## Changes

- Neutralized project title and documentation to **AGENTS.md Compact Reload** while preserving the Git repository name (`codex-agents-compact-reload`) for provenance and URL stability.
- Added multi-harness payload auto-detection in `src/reload-agents.mjs` supporting:
  - OpenAI Codex (`SessionStart` with `source: compact` emitting `additionalContext`);
  - Google Antigravity / Gemini (`workspacePaths` or `invocationNum` emitting `injectSteps`); and
  - Command-line streams (`--format=markdown|json`) for Claude Code, shell pipelines, and middleware.
- Formalized the Standardized 3-Tier Harness Support Model (Tier 1: Active Lifecycle Hook, Tier 2: MCP Ingestion, Tier 3: Persistent Directives).
- Created the dedicated `harnesses/` directory with detailed configuration guides for Codex (`harnesses/codex/`), Claude Code (`harnesses/cc/`), Antigravity (`harnesses/agy/`), and Cursor (`harnesses/cursor/`).
- Documented clean division of labor with Waymark's in-flight continuity ledger (`.waymark/`).
- Restructured `README.md` with Table of Contents and a complete repository directory tree.

## Verification

- `npm run verify`: 13 automated tests pass cleanly across Codex, Antigravity, Markdown, and JSON payload contracts.
- Syntax checks (`npm run check`) pass with zero warnings across all scripts, sources, and tests.
- Reconciled documentation references in companion repository `Waymark`.
