# v0.1.2 — Immediate means immediate

This patch moves the setup and cleanup skills into Codex's repository-discoverable `.agents/skills/` tree and prevents installation on Codex releases affected by delayed compact-hook delivery.

## Changes

- Require the operator to supply the exact active stable Codex version during installation.
- Reject versions older than Codex CLI 0.145.0 and reject prerelease version claims.
- Retain the asserted version, compatibility floor, and upstream fix commit in the installed `projects.json`.
- Add an automated regression for affected `0.144.x`, missing, and prerelease version inputs.
- Extend host acceptance to require immediate delivery after every compact boundary and no replay on the next non-compacting turn.
- Move both companion skills to `.agents/skills/` for native repository discovery.

## Upstream boundary

[openai/codex#28736](https://github.com/openai/codex/issues/28736) documented that automatic mid-turn compactions could defer `SessionStart(source=compact)` until a later turn. OpenAI fixed that host behavior in [`8c41ed33`](https://github.com/openai/codex/commit/8c41ed33ce3e39460e7b13b14c35e0c39bb5980d), first included in [stable Codex CLI 0.145.0](https://github.com/openai/codex/releases/tag/rust-v0.145.0).

This package cannot repair an affected host because the delayed payload does not identify its original compact boundary. It therefore rejects known-affected versions and requires live timing acceptance on the exact supported host.

## Verification

- `npm run verify`: 11 tests pass.
- Setup and cleanup skills pass the Codex skill validator from `.agents/skills/`.
- CI remains defined for Windows and Ubuntu on Node.js 20, 22, and 24.

Automated payload and installer tests do not prove a real manual or automatic compaction round trip. Follow [`docs/HOST-ACCEPTANCE.md`](../HOST-ACCEPTANCE.md) before treating the hook as a hard continuity dependency.
